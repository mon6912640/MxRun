# MxRun v0.1.7

## 下载与安装

1. 下载 `MxRun-v0.1.7-portable.zip`
2. 解压到**固定目录**（里面已有 `portable.txt`：数据写在同目录 `data\`，整个文件夹可搬）
3. 双击 `mxrun.exe`；「设置」里可开关开机自启（写 HKCU，不需要管理员）

## 本版内容

 - release.ps1: gh 登录检查兼容 "Logged in to github.com as X" 的输出格式（原来只认 "account X"，取不到时报 null array 中断）
 - @ 文件搜索兼容 anything 的 ae.exe：es.exe 找不到或调用失败时自动改用；设置页加检测/测试与 ae.exe 下载设置引导
 - 记录踩坑 34：agent shell 的 Job 对象会让 MxRun 拉不起 Electron 应用（静默退出），验证时须由 explorer.exe 启动；附 .bat+自检的无键盘验证法
 - 文档登记 tools/release.ps1（一条命令发版）+ 它踩的两个 PowerShell 坑
 - release.ps1: 原生命令统一走 Invoke-Native，避免 PowerShell 5.1 把 git/gh 的 stderr 当致命错误（会在打完标签后打断脚本）
 - release.ps1 小修：干跑（和被否决时）不再关掉运行中的实例
 - 加 tools/release.ps1：一条命令发版（改版本 -> 打包 -> 提交 -> 标签 -> 推送 -> GitHub Release）
